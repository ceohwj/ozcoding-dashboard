# 대시보드 브리프

> 인터뷰로 채운다. `(미확정)`은 아직 답을 받지 못한 항목.

## 1. 목적과 사용자
- 사용자: 식약처 보건의료분석 담당자(본인)
- 배경: 빈부격차로 병원별 진료비 차이가 크다는 이야기가 있음
- 목적: 병원별 진료비 격차를 **주기적으로** 확인
- 사용 맥락: 정기 점검/보고, **월 1회** 데이터 갱신(fetch→집계 스크립트 재실행)

## 2. 분석 초점
- 감염병, 특히 **호흡기 질환** 딥다이브
- 호흡기 범위: ICD-10 **J00~J99 전체** (주상병 `claim.main_sick` 기준)

## 3. 핵심 지표(KPI)
- 진료비 격차: **명세서 1건당 총진료비**(`rvd_rpe_tamt_amt`) — 기관별 평균/중앙값, 보험료 5분위별 비교
- 호흡기 건수 등 요약은 KPI 카드로 제공

## 4. 분석 축과 필터
- 시간: 2024-01 ~ 2025-12 (월 단위 가능)
- 병원 단위: **개별 기관(익명 ID, `claim.yid`)**. 데이터에 기관명 없음 — 종별(cl_cd)/권역(region_cd)은 보조 필터
- 빈부 지표: **보험료 5분위** (`patient.prem_quintile`, 98명 결측은 '미상' 처리)

## 5. 화면 구성
- 제안 구성 확정: ① 요약 KPI 카드 ② 호흡기 월별 추이(건수·건당 진료비) ③ 기관별 분포·순위(상/하위, 박스플롯·히스토그램) ④ 보험료 5분위 × 기관 히트맵(종별/권역 보조 필터)

## 6. 기술/형태/갱신 방식
- 정적 HTML + JS, 빌드 없음
- 데이터: `scripts/fetch-data.mjs` → 집계 → `data/processed/*.json` 스냅샷, 월 1회 재실행
- 공유: 내 PC에서만 열람 (외부 배포 없음)

## 7. 디자인
- 차분한 보고서형: 밝은 배경, 절제된 색, 한국어 (스크린샷을 보고서에 붙이기 좋게)

## 8. 범위 밖
- 호흡기(J00~J99) 외 감염병(A·B 코드), 외부 배포, 실시간 시트 조회
- 병원 이름 표기(데이터에 없음)
