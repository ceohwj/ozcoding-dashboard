# 결정 기록

|---|---|---|
| 2026-10-21 | 정적 HTML+JS, 빌드·외부 라이브러리 없음 | 월 1회 스냅샷 방식, 본인 PC에서만 열람 |
| 2026-10-21 | 집계는 `scripts/aggregate.mjs`로 JSON 생성, 화면은 JSON만 읽음 | 38k행을 매번 브라우저에서 계산하지 않기 위해 |
| 2026-10-21 | 호흡기 = 주상병 J로 시작, 외래(031)만 | 브리프 확정. 입원(624건)은 규모가 달라 격차를 왜곡 |
| 2026-10-21 | 기관 비교는 호흡기 청구 20건 이상만 (`analysis.minClaims`, 30→20) | 30건은 102곳 전부 의원이라 종별 비교 불가. 20건이면 상급종합병원 14곳이 포함됨. 건수가 적을수록 중앙값은 흔들림 |
| 2026-10-21 | 보험료 분위 결측(98명)은 '미상'으로 분리, 히트맵에서는 제외 | 분위 비교의 왜곡 방지 |
| 2026-10-21 | 서버는 `src/`, `data/processed/`만 서빙 | 원본 CSV·설정 노출 방지 |
| 2026-10-27 | 데이터 원본은 시트 유지, Supabase `kr_claims`에 사본 적재(`scripts/load-supabase.mjs`) | 갱신 자동화와 필터별 실시간 질의를 위해. 시트가 원본이라 입력 경로를 새로 만들 필요 없음 |
| 2026-10-27 | `kr_claims`는 명세서 1건=1행 평면 테이블(종별·권역·보험료 분위를 적재 때 조인), 환자 ID·출생연도 제외 | 링크 공개라 anon 키가 노출됨. 행 단위 준식별자 노출을 줄임 |
| 2026-10-27 | anon은 읽기 전용 정책만, 쓰기는 service_role | RLS 없이 두면 anon 키로 수정·삭제가 가능해짐 |
| 2026-10-27 | 화면은 supabase-js(CDN ESM, 버전 고정)로 호흡기 외래 행을 읽어 브라우저에서 집계. `aggregate.mjs`는 검증 기준으로 유지 | 사용자 지정(supabase-js). 13k행 수준이라 브라우저 집계로 충분 |
| 2026-10-27 | 공개 범위: 링크를 아는 누구나(GitHub Pages) | 인터뷰 확정. 기존 '본인 PC만'에서 변경 |
